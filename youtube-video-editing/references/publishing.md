# Publishing copy

Write in the channel's language and voice. Ask for any link you don't have; use `[lien]` placeholders for the video URL.

## YouTube
**Title**: the episode title, punchy, ≤ 70 chars, one emoji max.

**Description**
1. Two-line hook in first person (what I went to do → what I came back with), a concrete surprising number, one emoji.
2. The core question or premise, the people involved.
3. "Au programme" list, 3–5 lines, one emoji each, matching the chapters.
4. `⏱️ Chapitres` from the chapter-card positions (first must be `0:00`).
5. Links: every podcast/article/reel/product mentioned in the video, handle(s).
6. A one-line tone note if useful (not sponsored, not changing the channel's topic).
7. CTA: like/comment/share/subscribe, ask for topic ideas; tease the next episode if the video does.
8. `Crédits :` one line with every third-party asset and licence.
9. 5–8 hashtags.

Upload reminders: import the `.srt` in Subtitles, set the official thumbnail as custom thumbnail, check that names in the description match who actually appears after edits (inserts removed during feedback).

## YouTube community post
Short, first person, the premise, then a question → suggest publishing it as a **poll** with 3–4 options.

## LinkedIn
Default to a **launch announcement** tone ("Ça y est, elle est en ligne 🎬"): context (where/when), what I came back with, the concept in two lines, what you'll find (3–4 emoji bullets), a personal line about making it, link, a genuine question to the audience, hashtags.
- Kudos paragraph for people who inspired it: keep it **short and natural** (2–3 sentences), end with an invitation to comment ("X, si tu passes par là, donne-moi ton avis 😉"). Tell the user to type `@Name` and pick the profile so the tag notifies.
- Light-hearted PS tags for people involved ("PS : <Prénom>, désolé si je t'ai accaparé …") are welcome.
- Relative dates ("il y a 10 jours") → state the reference date so the user can adjust.

## X
3–4 lines: the premise, the surprising fact, the punchline gag word (e.g. "Spoiler : WASTED 💀"), link.

## Instagram (for the short)
Hook line with emoji, the surprising fact, "Spoiler" punchline, 3 emoji bullets of what's inside, a comment prompt, "La vidéo complète est sur YouTube, lien en bio", 6–8 hashtags. Suggest tagging the accounts of people/organisations featured so they can repost.
